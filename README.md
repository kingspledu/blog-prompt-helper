# 블로그 프롬프트 도우미

서식 규칙을 복사하고, 블로그 원문에 작성 지침을 붙여 복사하는 브라우저 도구입니다.

## 사용 방법

1. `index.html`, `gps-editor.js`, `gps-archive.js`를 같은 폴더에 다운로드하여 브라우저로 엽니다.
2. **서식규칙복사** 버튼으로 규칙 내용을 복사합니다. 파일 첨부가 필요하면 **규칙 파일 다운로드** 버튼을 누르고 다운로드된 TXT 파일을 채팅창에 끌어 놓습니다.
3. 블로그 원문을 입력하고 **프롬프트 복사** 버튼을 누릅니다.

프롬프트 구성: 안내문 → 줄바꿈 10번 → 원문 → 줄바꿈 5번 → 작성 지침.

입력한 원문은 브라우저에서만 처리되며 서버로 전송하거나 저장하지 않습니다. 클립보드 접근이 제한되는 환경에서는 수동 복사 창을 제공합니다.

## 파일

- `index.html`: 스타일과 스크립트 및 프롬프트를 포함한 실행 파일
- `서식규칙.txt`: 채팅창 첨부용 규칙 파일

설치나 별도 서버가 필요하지 않습니다.

## HTML 결과를 블로그에 붙여 넣기

3번 섹션에 LLM에서 작성한 HTML 코드(HTML 코드 블록도 지원)를 붙여 넣으면 미리보기가 나타납니다. **블로그 내용 복사** 버튼을 누르고 블로그 편집기에 붙여 넣으세요. 코드 문자열 대신 서식이 포함된 HTML과 일반 텍스트가 함께 복사됩니다. 편집기가 지원하는 서식에 따라 붙여넣기 결과가 달라질 수 있습니다. 미리보기에서는 스크립트와 이벤트를 실행하지 않습니다.

## 이미지 GPS 위치정보 수정

4번 섹션에서 GPS 삭제 또는 입력한 위도·경도로 변경을 선택하고 이미지를 열면 자동으로 수정됩니다. 다운로드 버튼으로 별도 파일을 저장합니다. JPG·PNG·WebP(최대 30MB)를 지원하며, HEIC·GIF·TIFF는 지원하지 않습니다.

EXIF GPS를 수정하고 결과를 다시 읽어 검증합니다. 기존 GPS 태그의 값도 지우며, 중복 위치정보가 남지 않도록 XMP 메타데이터를 제거합니다. 이미지 픽셀 데이터는 재압축하지 않고 원본 파일은 덮어쓰지 않습니다. 다른 EXIF 정보는 유지됩니다. EXIF/XMP 이외의 위치정보나 촬영지 식별 정보까지 제거하는 기능은 아닙니다.

이미지는 서버로 전송되지 않고 브라우저에서만 처리됩니다. 위도는 -90~90, 경도는 -180~180 범위의 십진수입니다. GPS가 없는 이미지에도 좌표를 추가할 수 있습니다.

`gps-editor.js`는 이미지 컨테이너와 EXIF GPS 처리를 담당합니다. 웹페이지를 로컬에서 사용하려면 `index.html`과 같은 폴더에 두세요.

형식 참고: [PNG 규격](https://www.w3.org/TR/png-3/), [WebP 규격](https://developers.google.com/speed/webp/docs/riff_container).
## 여러 이미지와 주소·즐겨찾기

여러 파일을 선택하면 한 장씩 순서대로 처리하며, 실패한 파일은 표시하고 나머지 파일을 계속 처리합니다. 파일당 30MB, 선택한 파일 전체 300MB까지 지원합니다. 수정 방식이나 좌표를 바꾸면 이전 결과를 무효화하고 원본 파일부터 다시 처리합니다.

개별 다운로드, 전체 ZIP 다운로드, 순서대로 다운로드를 제공합니다. ZIP에는 성공한 이미지 파일만 포함하며, 여러 파일은 순번을 붙여 같은 이름의 파일도 구분합니다. 순차 다운로드가 브라우저에서 차단되면 여러 파일 다운로드를 허용하거나 ZIP을 사용하세요.

주소 또는 장소명을 검색하고 결과를 선택하면 GPS 좌표가 적용됩니다. 국내 주소 검색은 [Photon](https://github.com/komoot/photon) 공개 서비스를 이용하며, 검색 버튼으로 요청한 검색어만 외부 서비스에 전송합니다. 이미지 파일은 전송하지 않습니다. 요청 간격을 제한하고 같은 페이지에서 검색 결과를 메모리에 캐시합니다. 검색 서비스 장애나 OpenStreetMap 데이터에 없는 상세 주소는 검색되지 않을 수 있으므로 즐겨찾기 또는 직접 좌표 입력을 사용할 수 있습니다.

즐겨찾기: NLCS, BHA, KIS, SJA, 제주신화월드, 오설록 티뮤지엄, 생각하는 정원, 환상숲곶자왈공원. 좌표는 시설의 대표 지점이며 특정 건물이나 정문 좌표와 다를 수 있습니다. 출처 및 확인일(2026-10-07)은 아래 데이터와 화면의 지도 링크로 확인할 수 있습니다.

- 좌표 데이터: `gps-places.json` (페이지에도 포함되어 오프라인 선택 가능)
- ZIP 생성: `gps-archive.js` (STORE 방식, 이미지 재압축 없음)
- 지도 데이터: [OpenStreetMap 기여자, ODbL](https://www.openstreetmap.org/copyright)
- 오설록 좌표: [한국관광공사](https://data.visitkorea.or.kr/linkedview/2660802)

3번 섹션의 HTML 결과는 원본 코드의 정렬 설정과 관계없이 전체 가운데 정렬로 표시하고 복사합니다. 표 자체도 가운데 배치합니다. 붙여넣기 결과는 블로그 편집기가 지원하는 서식에 따라 달라질 수 있습니다.

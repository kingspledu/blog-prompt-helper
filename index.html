블로그 프롬프트 도우미

서식 규칙을 준비하고, 블로그 원문을 작성용 프롬프트로 복사하세요.

1서식 규칙 준비

파일로 첨부하려면 다운로드한 서식규칙.txt를 채팅창에 끌어 놓으세요. ‘서식규칙복사’는 규칙 내용을 텍스트로 복사합니다.

2블로그 프롬프트 만들기

0자

안내문 → 줄바꿈 10번 → 원문 → 줄바꿈 5번 → 블로그 작성 지침

완성된 프롬프트 미리보기
원문을 입력하면 완성된 프롬프트가 표시됩니다.

3작성된 코드를 블로그로 바로 붙여넣기

자주 쓰는 이미지 보관함

명함·로고 등을 한 번 저장해 두고 다시 사용하세요. 각 이미지의 삽입 위치를 따로 선택할 수 있습니다. 이 브라우저에 저장되며 다른 기기와 동기화되지 않습니다.

JPG·PNG·WebP, 파일당 10MB·보관함 전체 100MB까지 지원합니다. 브라우저의 사이트 데이터를 지우면 저장한 이미지도 삭제됩니다.

저장한 이미지를 불러오는 중입니다.

‘블로그 내용 복사’에는 선택한 이미지가 함께 포함됩니다. 블로그 편집기가 이미지를 붙여 넣지 못하면 보관함의 다운로드 버튼으로 받아 직접 첨부하세요.

클릭해서 전화할 수 있는 번호

번호를 입력하면 전화 링크가 생성됩니다. 이미지마다 별도의 전화번호도 저장할 수 있습니다.

HTML 코드를 입력하면 아래에 미리보기가 나타납니다.

전체 글을 가운데 정렬하여 미리보기와 복사에 적용합니다. 복사 후 블로그 글쓰기 화면에 Ctrl+V 또는 ⌘V로 붙여 넣으세요. 서식은 블로그 편집기가 지원하는 범위에서 유지됩니다.

블로그 미리보기

4이미지 GPS 위치정보 수정

여러 이미지를 선택하면 한 장씩 순서대로 처리합니다. JPG·PNG·WebP, 파일당 30MB·전체 300MB까지 지원합니다.

제주 위치 즐겨찾기

장소를 선택하면 대표 좌표가 모든 이미지에 적용됩니다. 필요하면 위도·경도를 직접 조정하세요.

검색어는 Photon 지도 검색 서비스로 전송됩니다. 이미지는 전송하지 않습니다. © OpenStreetMap 기여자

지도·좌표 출처 확인

즐겨찾기·검색으로 선택한 이름이 자동 입력됩니다. 원하는 이름으로 바꿀 수 있습니다.

이미지는 브라우저에서만 처리합니다. 이미지 데이터는 재압축하지 않고, 촬영 방향 등 기존 EXIF 정보는 유지합니다. 중복 위치정보를 방지하기 위해 XMP 메타데이터는 함께 제거합니다.

수정된 전체 파일을 한 번에 ZIP으로 받거나 각 파일을 따로 받을 수 있습니다. 파일명과 압축파일명에 장소 이름·좌표가 포함됩니다. GPS 삭제 모드에서는 좌표를 넣지 않습니다. 순차 다운로드는 브라우저에서 여러 파일 다운로드를 허용해야 할 수 있습니다.

자동 복사를 사용할 수 없습니다. 아래 내용을 선택한 뒤 Ctrl+C 또는 ⌘C로 복사하세요.

자동 저장 · 입력 히스토리

입력 후 자동 저장하며, 입력을 잠시 멈추면 이전 버전을 기록합니다. 생성 후 24시간 이내의 최근 50개 기록을 같은 브라우저에서 불러올 수 있습니다. 기록은 각각 생성 후 24시간이 지나면 목록에서 사라집니다. 원문·HTML·전화번호·GPS 설정·이미지 삽입 설정을 저장합니다. GPS 작업용 업로드 파일은 다시 선택해 주세요.

JSON은 현재 입력값과 이미지 삽입 설정을 담습니다. 이미지 파일 자체와 히스토리는 포함하지 않습니다. 현재 입력은 불러오기 전 히스토리에 보관합니다. 마지막 자동 저장 입력은 히스토리 만료와 별도로 유지합니다.

과거 입력 히스토리 보기

리셋하면 입력과 GPS 작업 목록을 비웁니다. 이미지 보관함과 히스토리는 유지하며 이미지의 블로그 삽입은 해제합니다. 사이트 데이터를 삭제하면 저장 내용도 삭제됩니다.

본문과 이미지는 서버로 전송하지 않습니다. 이미지 보관함과 전화번호 설정은 이 브라우저에 저장됩니다.
